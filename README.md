# PJay Weather App

A simple weather application built with HTML, CSS, and JavaScript that provides current weather information and forecasts.

## Features

- Display current weather conditions
- Show temperature in Celsius/Fahrenheit
- Display weather icon based on conditions
- Simple 3-day forecast
- Search for locations by city name
- Responsive design for mobile and desktop

## Technologies

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API (or similar weather API)
